## ✅ Refactoring: *Extract Superclass*

### 🎯 Objetivo

Extraer una **superclase común** (por ejemplo `Ring`) para evitar duplicación entre `CharRing` e `IntRing`.

---

## 🔧 Pasos intermedios

1. **Identificar similitudes**

   * Ambas clases tienen:

     * `source` (array)
     * `idx`
     * método `next()`

---

2. **Crear la superclase**

```java
public abstract class Ring {
    protected int idx;

    public Ring() {
        idx = 0;
    }
}
```

---

3. **Mover atributos comunes**

* Pasar `idx` a `Ring`

---

4. **Generalizar comportamiento común**

* Declarar método abstracto en la superclase:

```java
public abstract Object next();
```

---

5. **Hacer que las clases hereden**

```java
public class IntRing extends Ring
public class CharRing extends Ring
```

---

6. **Eliminar duplicación**

* Quitar `idx` de las clases hijas
* Mantener solo lo específico (`int[]`, `char[]`)

---

7. **Implementar método en subclases**

```java
@Override
public Integer next() { ... }
```

---

8. **Verificar compatibilidad**

* Ajustar tipos (`Object`, `Integer`, `Character`)
* Ejecutar tests

---

## ⚠️ Posible inconveniente

* Uso de `Object` pierde tipado fuerte (no es ideal)
* Mejor solución real: usar **genéricos (`Ring<T>`)**, pero probablemente no es lo que pide el ejercicio

---

## 🧠 Resumen final

👉 Crear superclase
👉 Mover atributos/métodos comunes
👉 Hacer herencia
👉 Ajustar tipos
👉 Probar que todo siga funcionando
